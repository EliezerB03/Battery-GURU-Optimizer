## 📱 Requirements
* Android 13/One UI 5+ ROMs
* Device Supported: Samsung Galaxy S9/S9+/Note9/Note10 Lite (Exynos 9810)
* Kernel Supported: Apollo v6.5+/DS-ACK 1.0+ Kernels or Kernels Based on them
* ROOT access via KernelSU/Next/Apatch/Magisk

## 🧩 Features
* App with customizable settings based on One UI theme
* General undervoltage optimizations
* CPU clock limited: LITTLE/BIG (1690 Mhz)
* Power efficient enabled
* Storage optimizations
* ZRAM optimizations
* More tweaks/optimizations
